# Running CUBE jobs on hoopoe

A step-by-step workshop guide: log in to the hoopoe cluster, copy the shared
CUBE example, submit it with Slurm on CPUs, an A100 or H100 GPUs, watch the
queue and check the results.

Live page: https://balerahul.github.io/cube-workshop-hoopoe-guide/

- `index.html`, `styles.css`, `hoopoe.css`, `guide.js`, `assets/`: the page
- `jobs/`: the job scripts shown on the page; the same files are on hoopoe in
  `/storage/rahul-rcss/cube/examples/jobs`

Companion guide for running CUBE on your own computer:
https://balerahul.github.io/cube-workshop-user-machine-guide/
